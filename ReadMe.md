# 💫 About Me:
## 👋 About Me<br><br>I'm a **DevOps Engineer** with 5+ years of experience across DevOps, cloud infrastructure, system administration, and web technologies. I specialize in building, automating, deploying, and maintaining scalable and reliable cloud environments.<br><br>My primary focus is on **AWS Cloud Infrastructure, Infrastructure as Code (IaC), CI/CD automation, containerization, and deployment engineering**. I enjoy solving infrastructure challenges, streamlining deployment workflows, improving system reliability, and building solutions that scale.<br><br>### 🚀 What I Do<br>- Design, provision, and manage AWS cloud infrastructure.<br>- Automate infrastructure provisioning using **AWS CloudFormation**.<br>- Build and maintain CI/CD pipelines and deployment workflows.<br>- Containerize applications using **Docker** and manage container image workflows with Amazon ECR.<br>- Configure AWS services including **VPC, EC2, S3, Lambda, App Runner, CloudFront, Route 53, IAM, and Secrets Manager**.<br>- Manage domains, DNS configurations, SSL certificates, and cloud networking.<br>- Implement secure application deployments, monitoring, backup, and disaster recovery strategies.<br>- Work with Linux and Windows server environments, troubleshooting, and system administration.<br><br>### 🛠️ Technologies & Tools<br><br>**Cloud & Infrastructure:** AWS, CloudFormation, EC2, VPC, S3, Lambda, CloudFront, App Runner, Route 53, IAM<br><br>**DevOps & Automation:** Docker, Amazon ECR, GitHub Actions, CI/CD, Infrastructure as Code<br><br>**Databases & Messaging:** PostgreSQL, Redis, Amazon SQS, EventBridge<br><br>**Web & Application Infrastructure:** Nginx, Apache, Keycloak, REST APIs, DNS, SSL/TLS<br><br>**Operating Systems:** Linux, Windows Server<br><br>### 💡 What I'm Interested In<br>- Cloud architecture and infrastructure automation<br>- Scalable multi-tenant application infrastructure<br>- CI/CD optimization and deployment automation<br>- Cloud security and infrastructure reliability<br>- High availability, backup, and disaster recovery<br><br>I'm always exploring better ways to automate infrastructure, improve deployment processes, and build reliable cloud-native systems.<br><br>### 🤝 Let's Connect<br>I'm open to connecting with fellow engineers, collaborating on interesting projects, and sharing knowledge about DevOps and cloud technologies.
